# React Practice Projects

Small React apps I built while learning React, each in its own folder. All use Vite.
They work up from basic state to hooks, Context, and routing.

| Folder | What it covers |
| --- | --- |
| `02counter` | `useState` counter |
| `03tailwindprops` | Props and Tailwind styling with a `Card` component |
| `04bgChanger` | Background-color switcher |
| `05passwordgenerator` | `useState`, `useEffect`, `useCallback`, `useRef` |
| `06currencyconverter` | Currency converter with a custom hook |
| `07reactRouter` | Multi-page app with React Router |
| `08miniContext` | Minimal Context API example |
| `09themeswitcher` | Light/dark theme via Context |
| `10todocontextLocal` | Todo app using Context and localStorage |

## Running any project

```bash
cd 05passwordgenerator
npm install
npm run dev
```
